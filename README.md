# 🧮 Advanced Engineering & Calculus Calculator
This project is a professional engineering calculator developed in Python, focusing on **Chapter 7: Arrays and Exception Handling**.

### 🚀 Key Features:
- **Trigonometry**: Sine, Cosine, and Tangent using the `math` module (degrees to radians).
- **Calculus**: Symbolic Differentiation and Integration using `SymPy`.
- **Mathematical Tools**: Absolute value, Square root, Power, and Rounding (`ceil`/`floor`).

### 🛡️ Technical Implementation:
- **Error Handling**: Uses `try-except` blocks to manage input errors (like `ValueError`), ensuring the program is crash-proof.
- **Data Structures**: Concepts of Python Lists and Arrays were applied for structured data.
- **User Experience**: Safe input gathering through custom functions.

### 🏁 Final Status:
The code is optimized, documented, and ready for deployment.
