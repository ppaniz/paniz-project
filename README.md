# Advanced Engineering & Calculus Calculator
This is a professional Python calculator designed for engineering and calculus tasks.

### Key Features:
- **Basic Math**: Addition, Subtraction, Multiplication, and Division.
- **Trigonometry**: Sine, Cosine, and Tangent (converts degrees to radians).
- **Calculus**: Symbolic Derivative and Indefinite Integral using `SymPy`.
- **Advanced Math**: Absolute value and Square root.
- **Error Handling**: Uses `try-except` blocks to prevent crashes on invalid inputs.
